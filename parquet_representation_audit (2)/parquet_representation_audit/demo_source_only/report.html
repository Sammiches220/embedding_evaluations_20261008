Retail source audit · synthetic

Source information · schema-driven coverage and distributions · no embedding analyses

Source-only mode: geometry, probes and topology are unavailable. The tables describe observed source information.

Purity is the mean fraction of known neighbors sharing the anchor’s label. Lift divides that fraction by reference prevalence. A 5% segment with 30% purity has lift 6.

Micro weights positive anchor/label pairs; macro gives each audited label equal weight. Large lift with very little support needs scrutiny. Tag metrics count shared presence, and unannotated rows remain unknown.

Full source-population tables are exported separately; embedding measurements use the bounded evaluation cohort. Reference prevalence: evaluation. This report does not establish whole-population fidelity from a potentially selected sample. PCA is only an overview. An embedding-based predictor’s geometric coherence is not independent validation.

How to read intrinsic and extrinsic evidence

Diversity: what information varies here?

Category entropy rises when labels are more evenly mixed; it falls when fewer labels dominate. The same full-run vocabulary normalizes every subset. Tags use the average binary presence/absence entropy across audited tags, in bits. This differs from the tag-occurrence entropy in source_summary.json. Unknown annotations are excluded. Numeric features use variance rather than arbitrary entropy bins.

Neighborhood structure: is similar information nearby?

Local entropy measures the mix inside neighborhoods. Low local entropy alongside diverse source labels suggests local organization, but low entropy alone can simply reflect a dominant label. Small neighborhoods also underestimate entropy. Increasing k changes the spatial scale and sample size, so an upward entropy curve is not proof of worse embeddings.

Purity rises when neighbors share the anchor’s label; for tags, only shared positive tags count. Micro weights positive anchor/tag pairs and macro weights labels equally. Lift divides each label’s purity by its full-run reference prevalence before averaging; a lift of 1 is reference-level agreement. A large lift for a rare label can be unstable. Missing neighbors change the effective k, which you can inspect using known-neighbor share.

For numeric fields, lower absolute differences mean nearby values are closer in the field’s own units. A local/global variance ratio below 1 means neighborhoods vary less than the full source; its denominator stays fixed on selection. Moran’s I rises with stronger neighboring covariation, but its scale depends on the graph. Absolute differences and local variance are not comparable across differently scaled fields.

Linear probes: can this pipeline recover the feature?

A standardized logistic regression predicts categories or independent binary tags; standardized Ridge predicts numeric fields. These are trained once and evaluated on held-out rows. Region selection rescoring uses only its held-out rows and does not train a regional model. Balanced accuracy averages recall across observed test classes; numeric R² compares squared errors with variation in this test subset. R² can be negative. MAE remains in the feature’s units.

Green means the linear pipeline beats its training-only dummy baseline by the configured margin. Numeric color uses relative MAE improvement; categorical color uses balanced-accuracy gain. The baseline and probe share the same split. This is evidence of accessible information for this pipeline, not a universal feature ranking. Test difficulty, tag support, group leakage and annotation quality can change scores. Probe B uses the same rows and split as A; its B−A badge uses the displayed score’s direction, so check MAE for numeric trade-offs too. These are single-split comparisons without retraining intervals.

External evaluation: does an actual predictor agree with observed truth?

External scores compare supplied predictions with matched observed labels. If the predictor uses these embeddings, it measures that full pipeline; if it is independent, it can offer a different source of evidence. Predictions on unknown truth do not establish accuracy. Neighborhood coherence alone cannot validate a predictor. High scores do not establish complete or unbiased annotations.

Changes and confidence

Selected-row changes compare with all evaluated rows, which includes the selection. Neighbors and prevalence references stay fixed; the selection changes anchor rows only. Model differences are B minus A on shared evaluable anchors. The detailed paired-comparison CSV reports conditional bootstrap intervals; overview color thresholds provide no uncertainty guarantee. Trust across k requires checking effective support, candidate-pool scope and supplied graph fidelity. No single k is automatically trustworthy.

Scale to millions of rows

Feature counts and moments can be streamed. Neighborhood summaries can be batched over a precomputed approximate-neighbor graph, with graph recall audited on a sample. Exact all-pairs search and a full row snapshot are not suitable for 8 million rows. This implementation is an in-memory sampled audit: row controls have explicit size limits, while the aggregate feature view remains available. Production-scale probes require sampled or incremental training plus a held-out evaluation stream; this report does not implement that backend.

How these findings relate to representation quality

A radius filtration adds edges and fills cliques in a nested sequence. H0 records component mergers; H1 records loops that survive triangle filling. This bounded H1 calculation uses exact sample distances and GF(2) boundary reduction. A loop alive at the cutoff is right-censored, not proof of an infinitely persistent semantic feature. H2 is not computed.

Component entropy is known-row weighted conditional entropy using the fixed audited vocabulary. Tags use mean binary entropy; numeric fields use within-component variance divided by full-source variance. Whole known label/tag rows are shuffled within each sample, preserving its label counts and tag sets. At singleton and fully merged extremes, the permutation contrast is mechanically zero. Positive gap in between supports annotation organization for that null, with no automatic significance claim.

Different samples use the same radii; A/B use identical IDs. Unless radii are explicit, thresholds are pooled pair-distance quantiles across models and repeated samples in each geometry. Repeated-sample min/max ranges are descriptive rather than confidence intervals. Correlated posts, incomplete annotations and source artifacts can still explain structure.

Chordal distance uses unit-normalized directions; raw Euclidean distance also uses magnitude. Their barcode scales differ. Topology can remain meaningful while linear separability changes. Stable loops or components require task-relevant labels or examples before being called useful; the number of loops is not an embedding-quality score.

Ordinary normalization probes compare fixed regularization unless a multi-value grid enables training-only CV. Ridge uses alpha; logistic regression uses C, its inverse penalty strength. The outer split and group policy are identical between variants. No encoder is retrained and no hyperspherical training objective is imposed.

At millions of rows, use bounded matched samples or an independently validated sparse/ANN backend. Exact all-pairs persistence is not supplied for that scale. Limits and skipped analyses are reported explicitly; the main feature overview remains available.
